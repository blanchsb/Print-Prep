This extension is useful for prepping objects and characters for 3D printing.

It was specifically designed to support FDM multi-color 3D printing. 
Features include:
easily cut and key objects; 
add FDM material shader with layer lines; 
paint objects using vertex color attributes; 
printer proxy and demo character; 
object orientation and placement tools; 
color match placement options that are keyframed revert-friendly;
animated printer rig with live follow cursor operator;
